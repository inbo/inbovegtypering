# Connect to the INBO database

Connect to the INBO database

## Usage

``` r
connect_db_inboveg(db = "D0010_00_Cydonia", test = FALSE)
```

## Arguments

- db:

  The name of the INBO hosted database. Defaults to Cydonia db

- test:

  flag whether the test modus is used

## Value

connection object
